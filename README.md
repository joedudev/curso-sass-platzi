## 📖 Sobre el proyecto

Este repositorio contiene el proyecto práctico del **Curso de Fundamentos de Sass: Crea tu Primera Landing Page** de [Platzi](https://platzi.com), impartido por Ana María Díaz Solorio. El objetivo es desarrollar una landing page con el preprocesador **Sass**, usando variables, mixins y herencia para simplificar y organizar los estilos CSS, y publicarla con Netlify.

## ✨ Lo que se construye

- 🧭 **Navbar** con nesting y `@rules` de Sass
- 🦸 **Sección hero** con Flexbox y Sass
- 🛍️ **Catálogo de productos** con product cards reutilizando estilos mediante herencia
- 💡 **Sección "Por qué nosotros"** con Sass y Flexbox
- 🖼️ **Galería** con estilos y animaciones
- 📍 **Sección de ubicación y footer**
- 🌐 **Deploy** del sitio con Netlify

## 🧠 Conceptos practicados

| Área                   | Temas                                                  |
| ---------------------- | ------------------------------------------------------ |
| 🧩 Fundamentos de Sass | Qué es Sass, preprocesadores CSS, compilación          |
| 🔧 Reglas y uso        | Variables, scope, selectores, nesting, `@rules`        |
| 🔢 Expresiones         | Números, strings, colores y booleanos                  |
| 🧬 Herencia            | `@extend` y selectores placeholder                     |
| ♻️ Mixins              | `@mixin` / `@include`, mixins con parámetros (Flexbox) |
| ➗ Funciones           | Operadores y funciones en Sass                         |
| 🎯 Maquetación         | Flexbox aplicado a hero, tarjetas y secciones          |
| 🚀 Deploy              | Publicación del sitio con Netlify                      |
